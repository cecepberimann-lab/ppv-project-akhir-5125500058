# Proyek Akhir - Aplikasi Catatan / Manajemen (Sprint 4)

Aplikasi ini dikembangkan sebagai bagian dari Proyek Akhir Praktikum Pemrograman Platform Web (PPV).

## Fitur Utama (MVP)
- Penambahan dan pengelolaan data secara interaktif.
- Penyimpanan lokal aman (`Secure Storage`) menggunakan versi kunci `v1`.
- Antarmuka berbasis komponen modular ES6 yang aman dari XSS.

## Cara Menjalankan
1. Clone repository ini atau buka folder proyek.
2. Jalankan server lokal (misalnya menggunakan ekstensi Live Server di VS Code).
3. Buka `index.html` di browser.
